# 功能与验收边界

目标是自有、无广告 SDK、源码可读的 Android / iOS 客户端。当前已提供「发现 / 搜索 / 片单 / 设置」界面、片源选择、剧集详情、播放器、缓存管理及 JSON 导入导出入口。平台接口、内容权限与客户端自身功能分开验收。公开影片示例始终明确标识，不冒充红果片源。

| 功能 | 当前实现 | 验收范围 |
| --- | --- | --- |
| 浏览与搜索界面 | 按片源加载分类目录、分页追加、关键词搜索、350ms 联想、详情与每组 50 集选集 | 界面源码已实现；实际内容以 provider 返回为准，网络与真机行为仍需验收 |
| 播放界面 | 原生视频控制条、倍速、分集、自动连播、清屏、全屏与 PiP 配置、进度保存 | 已接入播放器组件；平台支持、事件顺序、编解码、PiP 和旋转仍需目标设备验收 |
| 自备 HTTPS 媒体目录 | 严格 v1 JSON 校验、搜索、标签分类、分页、分集、明确的下载许可标记 | Node 测试覆盖源/剧目/分集精确匹配及 URL 校验 |

## 独立 Shadowrocket 扩展

已将此前的 `hongguo-shadowrocket.sgmodule`、`hongguo-shadowrocket-copy.txt`、`hongguo-shadowrocket-使用说明.txt` 原样纳入 [extensions/shadowrocket](../extensions/shadowrocket/README.md)，原输出文件保持不变。目录包含 MIT LICENSE、上游固定提交与三个 SHA-256、安装/订阅说明。

5 个静态测试覆盖原文件字节指纹、模块/复制文本一致性、18 条域名规则、3 条重写正则与正常媒体/账号/无关网址放行、5 个 MITM 主机、完整 MIT 署名及无外部脚本/证书/私钥。需要 HTTPS URL 重写时，在用户自己的 Shadowrocket 中生成并信任 CA；域名拦截不依赖 MITM。转换有通配近似，不能模拟激励广告发奖或保证全广告清除；尚未真机导入/实播。

## 自备媒体目录格式

目录采用如下结构；示例媒体可替换为你有权使用的 HTTPS 链接。`downloadable` 缺省时不开放导出。

```json
{
  "version": 1,
  "id": "my-owned-videos",
  "name": "我的影片",
  "attribution": "来源、作者、许可说明",
  "dramas": [{
    "id": "film-1",
    "title": "影片名称",
    "description": "简介",
    "tags": ["自备"],
    "episodes": [{
      "id": "ep-1",
      "title": "第一集",
      "url": "https://example.com/owned-video.mp4",
      "mimeType": "video/mp4",
      "downloadable": false
    }]
  }]
}
```

输入 JSON 文本与累计本地资料均限制为 2 MiB，单目录最多 1000 部、总计 10000 集；单部最多 1000 集。移除目录保留既有收藏和观看记录，避免意外丢失；再次导入同一来源 id 后可恢复查找。远程地址可过期或不可达，解析目录成功不意味着媒体可用。

备份 schema 为 `honguo-diance-quguanggao.backup`，版本为 1；下载文件不会进入备份。恢复后不能凭旧设备路径直接播放，需重新下载。

## 需要分别验证的能力

- 红果实时目录、搜索、分集及取流以 provider 实际返回为准；受保护、登录、风控或接口变化显示真实状态，不用示例片替代。
- Android 与 iOS 原生构建、签名、安装、后台下载、PiP、系统全屏/方向、实际编解码和离线播放必须在对应平台验收，Web 导出成功不代表原生已通过。
- 弹幕、评论、账号云同步、投屏、跨设备同步、复杂下载合并、TV 遥控和跨季自动推荐不因参考项目曾提供就算本项目已完成。
- 突然杀进程时操作系统可能来不及完成最后一次磁盘写入；页面应持续保存进度，并在退后台/退出播放器时提交最新值。若存储报错，改动会保留于本次内存并展示错误。
